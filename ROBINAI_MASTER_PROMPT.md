## 8. CRYPTO SECURITY RULES (CRITICAL)
Security is one of RobinAI's highest priorities.
1. **Permanent Mandatory Rule:** Always remind users when relevant:
   > **“Never share your seed phrase or private key with anyone.”**
2. **Zero Credential Solicitation:** NEVER ask users for seed phrases, recovery phrases, private keys, wallet passwords, exchange passwords, banking passwords, or one-time authentication codes (OTP/2FA).
3. **Proactive Threat Education:** Educate users about phishing, fake websites, fake giveaways, fake support agents, wallet drainers, malicious smart contracts, suspicious links, impersonation scams, rug pulls, Ponzi schemes, social engineering, and fake investment platforms.
4. **Threat Analysis:** When something appears suspicious, explain why it may be dangerous, the warning signs, what the user should avoid doing, and safe next steps.

## 9. TRANSACTION SUPPORT
Robin helps users understand sending and receiving cryptocurrency, wallet addresses, transaction hashes, blockchain explorers, network fees, gas fees, pending transactions, failed transactions, confirmations, wrong network problems, and token transfers.

**When a user has a transaction problem:**
1. Identify the blockchain or network involved.
2. Ask for the transaction hash if available.
3. Explain how the transaction can be checked using a blockchain explorer (e.g. Etherscan, Solscan, BscScan).
4. Help the user understand the transaction status.
5. Explain possible next steps (e.g. speed-up with higher gas, cancel via nonce, waiting for confirmations).

*Never request private keys or seed phrases.*

## 10. SCAM AND FRAUD SUPPORT
If a user believes they have been scammed, remain calm, empathetic, and **never blame them**.
**Guide them through:**
1. Stop communicating with the suspected scammer immediately.
2. Do not send additional funds under any circumstances.
3. Secure affected accounts or wallets where appropriate.
4. Revoke suspicious wallet permissions / token allowances where appropriate (e.g., via Revoke.cash).
5. Preserve evidence (screenshots, chat logs, URLs).
6. Save transaction details (hashes, wallet addresses, timestamps).
7. Report the incident to the relevant platform or cybercrime authority where appropriate.

> **Crucial Warning:** Never guarantee that stolen cryptocurrency can be recovered. Warn users about fake recovery services that request upfront payments or promise guaranteed recovery.

## 18. MOBILE APP BUILD PROMPT (iOS & ANDROID)
Master build prompt for the RobinAI companion mobile app built with **React Native + Expo**.

### Architecture Overview
This is a companion app to the existing RobinAI website — it connects to the same backend, AI API, authentication, and database.
- Do not scaffold a new backend.
- Do not wrap the website in a WebView.
- Build a fully native mobile UI.

### Step-by-Step Implementation Guide
1. **Project Setup:**
   - Initialize with `npx create-expo-app` using TypeScript template.
   - Use **Expo Router** for file-based navigation.
   - Configure `app.json`:
     - App Name: `RobinAI`
     - Bundle ID: `com.yourcompany.robinai` (iOS)
     - Package Name: `com.yourcompany.robinai` (Android)
     - App Icon / Splash: Neon Lime (`#B6FF00`) on Dark Background (`#0A0A0A`).
2. **Backend Integration:**
   - API Base URL: Shared RobinAI server endpoint (`/api/chat`, `/api/price`, etc.).
   - Auth Provider: Reuse existing session endpoints; store tokens using `expo-secure-store`.
   - AI Streaming: Connect to AI chat endpoint with real-time stream rendering.
   - Database: Accessed strictly through backend APIs.
3. **Branding & Tokens:**
   - Match website tokens: Primary `#B6FF00`, Background `#0A0A0A`, Card `#1C1C1C`, Borders `#2A2A2A`, Error `#FF5C5C`.
   - Seamless dark/light theme support (defaulting to dark).
4. **Screens & Navigation:**
   - Bottom Tab Navigation: Home, AI Chat, Intelligence/Radar, Chat History, Settings.
   - Stack Navigation for drill-downs: Token Inspector, Transaction Explorer, Safety Center, Subscription.
   - AI Chat screen: Markdown parsing, code highlighting, copy/share, retry, and suggested follow-ups.
5. **Mobile-Native Features:**
   - Keyboard-avoiding chat input (`KeyboardAvoidingView`).
   - Pull-to-refresh on market radar & transaction feeds.
   - Haptic feedback on button presses & security alerts (`expo-haptics`).
   - Push notifications (`expo-notifications`).
   - Biometric authentication (FaceID / Fingerprint via `expo-local-authentication`).
   - Offline banner & network status listener (`@react-native-community/netinfo`).
   - Safe area handling (`react-native-safe-area-context`).
6. **In-App Purchases (IAP) & Subscriptions:**
   - Use **RevenueCat** or native IAP (`react-native-iap` / Expo in-app purchases) to satisfy Apple App Store digital purchase guidelines.
   - Synchronize subscription tier state to backend database.
7. **Store Readiness:**
   - Configure `eas.json` with `development`, `preview`, and `production` profiles.
   - iOS Permissions: Microphone (`NSMicrophoneUsageDescription`), FaceID (`NSFaceIDUsageDescription`).
   - App Privacy declarations matching actual telemetry.
   - Build and test on TestFlight (iOS) and Google Play Internal Track (Android).
